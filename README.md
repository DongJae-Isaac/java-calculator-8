# java-calculator-precourse
# 기능 목록

## 1. 입력 기능
- [x] 사용자로부터 문자열 입력받기 (Console.readLine())
- [ ] 빈 문자열 입력 시 0 반환

## 2. 구분자 처리
- [ ] 기본 구분자(쉼표, 콜론)로 문자열 분리
- [ ] 커스텀 구분자 추출 ("//구분자\n" 형식)
- [ ] 커스텀 구분자로 문자열 분리

## 3. 계산 기능
- [ ] 분리된 문자열을 숫자로 변환
- [ ] 숫자들의 합계 계산

## 4. 예외 처리
- [ ] 음수 입력 시 IllegalArgumentException 발생
- [ ] 숫자가 아닌 값 입력 시 IllegalArgumentException 발생

## 5. 출력 기능
- [ ] "결과 : [숫자]" 형식으로 출력
## 구현해야할 것

- 입력값 : 문자열 (쉼표와 콜론을 구분자로 가지는) - readLine() 사용하기
1. 쉼표(,), 콜론(:)을 구분자로 가지는 문자열 전달
2. 구분자를 기준으로 분리한 각 숫자의 합을 반환
3. 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 종료
- 추가 조건: 기본구분자(쉼표, 콜론)외에 커스텀 구분자 지정 가능.
- 커스텀 구분자: 문자열 앞부분의 "//"와 "\n"사이에 위치하는 문자

## 세부조건

- 입력 라이브러리는 Console의 readLine()사용 -> 구현 완료
- 입력값이 공백일 경우 0 출력 -> 구현 완료

## 구현 순서
1. 일단 기본 구분자 먼저 구분
2. 커스텀 구분자 구분

## 수행 순서

1. 입력값이 공백인지 확인
2. 커스텀 구분자 구분
3. 기본 구분자 구분
